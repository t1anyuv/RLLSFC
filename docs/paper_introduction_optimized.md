# 论文 Introduction 优化版本

## 1. 背景介绍

轨迹（Trajectory）是一类典型的时空数据，记录移动对象（如车辆、行人）在一段时间内的连续位置变化，可形式化表示为

$$tr = \{(t_s, lat, lon)\}_{t=1}^T$$

其中 $t_s$ 代表时间戳，$lat, lon$ 表示地理坐标。随着移动设备与传感器的普及，轨迹数据呈爆炸式增长，并成为轨迹模式挖掘、路径预测、兴趣点识别等任务的重要基础。

在大规模轨迹管理场景中，键值数据库（Key-Value Store）因其高吞吐写入能力与低查询时延，被广泛用于轨迹存储与检索。轨迹通常以 Key 建立定位，以 Value 存储具体轨迹本体，为了支持高效查询，需要为 Key 构建一维索引结构。

空间填充曲线（Space-Filling Curve，SFC）是一种被广泛使用的映射编码方式，可将多维数据映射到一维键空间，以保持空间邻近性并提升索引局部性。

在现有系统中，XZ2 是最常用的 SFC-Based 轨迹索引方式。XZ2 通过四叉树递归划分空间并生成编码，然后使用某个子空间的编码来表示轨迹；其编码采用深度优先遍历顺序，可有效保持纵向空间连续性。

作为一种固定策略的 SFC，XZ2 只能保证纵向空间的编码局部性，而其他方向的编码值差距很大，固定的节点访问顺序也使其不能根据轨迹的空间分布特性进行动态调整，影响查询性能。

## 2. 挑战分析

为突破固定策略 SFC 的局限性，提高查询效率，需要在键值存储架构下设计一种支持任意遍历顺序的学习型SFC，这会面临以下挑战：

### 挑战一：节点访问价值难以衡量且随过程变化

若遍历顺序任意，每个节点的访问顺序不再由固定规则决定。节点访问价值不仅与其空间位置、轨迹数量等自身属性有关，还会受已访问节点影响，呈动态变化。具体而言：

- **多维度特征融合困难**：节点价值需要同时考虑轨迹统计特征（如轨迹数量、轨迹分布密度）、空间几何特征（如空间位置、与已访问节点的距离）、结构特征（如四叉树层级、单元格面积）以及遍历状态特征（如已访问比例）。如何将这些异构特征有效融合成统一的节点表示，是首要难题。

- **动态依赖关系复杂**：节点的即时价值不仅取决于其自身属性，还强烈依赖于当前已访问的节点序列。例如，一个节点在遍历初期可能价值较高，但随着相似节点的访问，其剩余价值会显著下降。这种动态依赖关系使得传统的静态评估方法失效。

- **实时评估计算开销**：在遍历过程中，每一步都需要重新评估所有候选节点的价值，涉及大量相似度计算（如Jaccard相似度）和空间距离计算。如何在不影响决策质量的前提下，降低实时评估的计算开销，是实际部署的关键问题。

### 挑战二：缺乏可用于优化的评价指标

目前对 SFC 的优劣评估主要依赖查询阶段指标，例如扫描记录数量或查询耗时，但这类指标仅反映查询结果，无法在编码阶段体现区域密度、轨迹分布等重要因素。具体问题包括：

- **查询效率与空间结构的权衡**：理想的评价指标需要同时考虑查询效率（如减少扫描区间数量）和空间结构特性（如保持轨迹的空间聚集性）。然而，这两个目标往往存在冲突：过度追求空间局部性可能导致查询时需要扫描更多不相关的区域，而过度追求查询效率可能破坏空间连续性，影响缓存性能。

- **多查询负载的泛化性**：不同应用场景下的查询模式差异巨大（如热点查询 vs. 均匀查询），单一的评价指标难以在不同查询负载下都表现良好。需要设计能够适应多样化查询模式的评价机制。

- **端到端优化目标缺失**：现有的评估方法通常在编码完成后才进行评估，无法在编码过程中提供即时的优化信号。这导致无法使用基于梯度的优化方法，只能依赖启发式策略。

### 挑战三：遍历空间组合爆炸，直接优化不可行

四叉树深度越大，候选节点序列呈指数增长，传统穷举或启发式策略难以在高维空间内找到接近最优的遍历路径。具体表现为：

- **动作空间规模巨大**：对于包含数千个节点的四叉树，每一步的候选动作数量可能达到数百个，整个遍历序列的组合空间为 $O(n!)$，其中 $n$ 为节点数量。即使使用启发式剪枝，搜索空间仍然过于庞大。

- **长期依赖关系**：最优遍历顺序需要考虑长期收益，即当前选择的节点不仅影响下一步，还可能影响后续数十步甚至整个序列的性能。这种长期依赖关系使得贪心策略难以找到全局最优解。

- **训练效率与收敛性**：在如此巨大的搜索空间中，如何设计高效的探索策略，确保训练过程能够在合理时间内收敛到高质量解，是强化学习方法面临的核心挑战。

## 3. 方法概述

针对上述挑战，我们提出了一种用于高效轨迹索引的学习型空间填充曲线。该 SFC 通过强化学习动态调整四叉树节点的编码顺序，从而适应多样化的查询负载。

### 针对挑战一的解决方案：多特征融合的节点表示与动态奖励机制

**节点特征表示设计**：我们构建了融合多类空间特征的12维节点表示向量，包括：

- **轨迹统计特征**（4维）：$N_{ee}$（被扩大元素覆盖的轨迹数量）、$N_{int}$（与轨迹MBR的交集数量）、$N_{cov}$（覆盖轨迹MBR的数量）、$D_{center}$（轨迹集合的密度中心坐标）。这些特征捕捉了节点在轨迹分布中的重要性。

- **空间几何特征**（4维）：$\Delta x, \Delta y$（节点中心相对于整体空间中心的偏移）、$\Delta dx, \Delta dy$（轨迹密度中心相对于扩大元素中心的偏移）。这些特征编码了节点的空间位置信息。

- **结构特征**（3维）：$L$（层级归一化值）、$S$（对数面积）、$qcode$（最大层级归一化编码）。这些特征反映了节点在四叉树结构中的位置。

- **遍历状态特征**（1维）：$\rho$（已访问节点比例）。该特征使模型能够感知当前遍历进度。

**动态奖励函数设计**：我们设计了同时考虑查询效率与空间相似性的混合奖励函数：

$$R = w_{local} \cdot R_{local} + w_{global} \cdot R_{global}$$

其中局部奖励 $R_{local}$ 结合了邻近性奖励和Jaccard相似度：

$$R_{local} = \alpha \cdot R_{proximity}(c_t, c_{t+1}) + \beta \cdot J(c_t, c_{t+1})$$

其中 $R_{proximity}$ 基于节点中心距离计算，$J$ 为Jaccard相似度，用于衡量两个节点轨迹集合的重叠程度。全局奖励 $R_{global}$ 在episode结束时计算，基于学习顺序与基线顺序的查询成本差异：

$$R_{global} = \text{normalize}(\text{baseline\_cost} - \text{learned\_cost}) \times \text{scale}$$

这种设计使得模型能够在每一步获得即时的空间相似性反馈，同时在episode结束时获得基于实际查询性能的全局优化信号。

**计算效率优化**：为了降低实时评估的计算开销，我们引入了轨迹到单元格的索引映射机制，将Jaccard相似度计算的时间复杂度从 $O(N \times T)$ 降低到 $O(T)$，其中 $N$ 为单元格数量，$T$ 为轨迹数量。同时，我们支持预计算相似度矩阵，进一步将相似度查询优化到 $O(1)$。

### 针对挑战二的解决方案：基于查询成本的端到端优化目标

**成本模型设计**：我们定义了可量化的查询成本模型，将空间相似性转化为查询效率指标：

$$\text{Cost}(Q, \pi) = \tau_{loc} \cdot \sum_{i} \text{loc\_cost}(I_i) + \tau_{scan} \cdot \sum_{i} \text{scan\_cost}(I_i)$$

其中 $Q$ 为查询集合，$\pi$ 为遍历顺序，$I_i$ 为查询 $q_i$ 需要扫描的区间集合。$\tau_{loc}$ 和 $\tau_{scan}$ 分别表示定位成本和扫描成本的权重系数。该模型将空间关系（通过区间数量体现）直接映射到查询性能指标。

**多查询负载适应**：我们支持三种查询生成模式（热点查询、均匀查询、混合查询），并在训练过程中使用参考查询集计算全局奖励。这使得学习到的遍历顺序能够适应不同的查询分布模式。

**端到端优化机制**：通过将查询成本差异作为全局奖励，我们实现了从空间关系到遍历顺序的端到端映射。模型在训练过程中直接优化查询性能，而非间接优化空间相似性，从而确保学习到的顺序在实际查询场景中表现优异。

### 针对挑战三的解决方案：基于强化学习的序列决策与搜索空间压缩

**马尔可夫决策过程建模**：我们将遍历顺序的生成建模为马尔可夫决策过程（MDP）：

- **状态空间**：当前节点的12维特征向量，编码了节点的多维度属性。
- **动作空间**：当前节点可访问的所有候选节点（通过八方向邻居、父节点、子节点搜索确定）。
- **奖励函数**：如前述的混合奖励机制。
- **策略网络**：使用Actor-Critic架构，Actor网络输出动作概率分布，Critic网络估计状态价值。

**搜索空间压缩机制**：为了应对组合爆炸问题，我们引入了多层次的搜索空间压缩策略：

1. **哑节点剪枝**：在四叉树构建阶段，我们根据轨迹数量阈值对稀疏节点进行剪枝，将轨迹上移到父节点。这显著减少了有效节点数量，压缩了动作空间。

2. **Top-K动作过滤**：在训练过程中，我们根据节点相似度动态选择Top-K个最相似的候选节点作为有效动作。Top-K值随训练进度动态衰减（从 $K_{start}$ 衰减到 $K_{final}$），在训练初期允许更多探索，后期聚焦于高价值动作。

3. **相似度矩阵预计算**：我们支持预计算所有节点对的Jaccard相似度矩阵，避免训练过程中的重复计算，显著提升训练效率。

**训练策略优化**：我们使用Advantage Actor-Critic (A2C)算法，通过优势函数减少方差，加速收敛。同时，我们实现了早停机制，当连续多个评估周期的改进率差异小于阈值时自动停止训练，避免过拟合。

## 4. 贡献总结

本文的主要贡献包括：

1. **提出了学习型空间填充曲线框架**：首次将强化学习应用于SFC的节点遍历顺序优化，实现了从固定策略到自适应策略的突破。

2. **设计了多特征融合的节点表示方法**：通过融合轨迹统计、空间几何、结构特征和遍历状态特征，构建了能够捕捉节点动态价值的统一表示。

3. **建立了端到端的查询成本优化模型**：将空间相似性转化为可量化的查询性能指标，实现了从空间关系到遍历顺序的直接映射。

4. **实现了高效的搜索空间压缩机制**：通过哑节点剪枝、Top-K动作过滤和相似度矩阵预计算，在保证解质量的前提下显著提升了训练和查询效率。
